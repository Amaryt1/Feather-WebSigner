# Feather WebSigner

واجهة ويب لتوقيع IPA محليًا داخل المتصفح، مع رفع ملفات فعلي إلى API اختياري على استضافة PHP.

## الرفع الفعلي

الواجهة تستخدم `XMLHttpRequest` لرفع P12 وMobileProvision وIPA إلى `UPLOAD_ENDPOINT` وتعرض:

- نسبة الرفع لحظة بلحظة.
- سرعة الرفع.
- الوقت المتبقي التقديري.
- إشعار نجاح بعد استلام الخادم للملف.
- معرفًا عشوائيًا للملف بدل كشف مسار التخزين.

نقطة الرفع موجودة في `api/upload.php`، والتخزين في `api/storage` محمي من الوصول العام على خوادم Apache عبر `.htaccess`.

### مهم جدًا مع GitHub Pages

GitHub Pages يستضيف ملفات ثابتة ولا يشغّل PHP. لذلك وجود `api/upload.php` داخل المستودع وحده لا يجعل الرفع يعمل على رابط `github.io`.

لتفعيل الرفع الحقيقي للزوار يجب نشر مجلد `api` على استضافة PHP تدعم `multipart/form-data`، ثم تغيير `src/config.js` إلى رابط HTTPS لذلك الـAPI، مثل:

```js
export const UPLOAD_ENDPOINT = "https://your-domain.example/api/upload.php";
```

إذا كان الـAPI على نطاق مختلف، يجب ضبط CORS في الخادم للسماح لنطاق الموقع فقط، وليس `*`.

## التوقيع

- تحميل `zsign-wasm` عند الحاجة.
- قراءة `Info.plist` واستخراج Bundle ID واسم الحزمة والملف التنفيذي واسم العرض.
- استبدال `embedded.mobileprovision`.
- توقيع Mach-O الداخلي ثم التطبيق الرئيسي.
- إعادة بناء `CodeResources`.
- تنزيل IPA الموقعة محليًا.
- دعم رابط تثبيت `itms-services` عند توفير Manifest صالح عبر HTTPS.

## الأمان

- لا تُرسل كلمة مرور P12 إلى API.
- P12 يحتوي على مفتاح خاص؛ لا تستخدم رفعًا غير مشفر.
- يجب منع الوصول المباشر إلى التخزين، وتحديد حجم الملفات، ومراجعة سياسة الاحتفاظ والحذف.
- استخدم فقط الشهادات وملفات Provisioning التي تملك حق استخدامها.
